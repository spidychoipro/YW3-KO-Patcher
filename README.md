# 요괴워치3 스키야키 한국어 패치 적용기

일본판 본편과 Update 4.0을 선택하면, 제작팀의 공식 한글 패치를 내려받아 적용하는 **Windows 앱**입니다.

**[최신 앱 다운로드](https://github.com/spidychoipro/YW3-KO-Patcher/releases/latest/download/YW3-KO-Patcher.exe)** · [릴리스](https://github.com/spidychoipro/YW3-KO-Patcher/releases) · [변경 기록](CHANGELOG.md) · [문제 신고](https://github.com/spidychoipro/YW3-KO-Patcher/issues)

> [!IMPORTANT]
> **본편과 한글 업데이트는 한 세트입니다. 둘 다 설치해야 합니다.**
> 본편만 실행하면 한글이 네모로 깨지거나 일본어가 남을 수 있습니다.
> 앱에서 패치를 만드는 것과 에뮬레이터·3DS에 업데이트를 설치하는 것은 별도 단계입니다.

## 1. 준비하기

| 준비물 | 내용 |
| --- | --- |
| 앱 | 위 링크의 `YW3-KO-Patcher.exe` |
| 본편 원본 | **일본판 요괴워치3 스키야키 v0**. CIA 또는 복호화 CCI 권장 |
| 업데이트 원본 | 같은 게임의 **Update 4.0 CIA** |
| 인터넷 | 첫 실행 시 패치 파일·필요한 도구 다운로드 |
| 저장 공간 | **12GB 이상 여유 권장**. 입력 형식과 변환 과정에 따라 더 필요할 수 있음 |

게임 원본은 직접 준비해야 합니다. 이미 한글 패치한 파일을 원본 칸에 넣지 마세요. 암호화된 CIA도 선택할 수 있으며, 일반적인 CIA 처리에서는 **키 파일 (선택)** 칸을 비워 두어도 됩니다.

## 2. 한글 패치 만들기

1. 앱을 실행하고 **① 본편 롬**에 일본판 본편을 선택합니다.
2. **② 업데이트 파일**에 Update 4.0 CIA를 선택합니다.
3. **③ 저장 위치**를 확인하고 **한글 패치 시작**을 누릅니다.
4. 완료 메시지가 뜨면 저장 폴더를 엽니다. 처음에는 다운로드와 대용량 파일 처리에 시간이 걸립니다.

원본은 덮어쓰지 않고 아래 결과물을 새로 만듭니다.

| 결과 파일 | 용도 |
| --- | --- |
| `YW3_Sukiyaki_KO_base.cci` | 에뮬레이터에서 열어 실행할 본편 |
| `YW3_Sukiyaki_KO_base.cia` | 설치해서 실행할 본편 |
| **`YW3_Sukiyaki_KO_update4.cia`** | **에뮬레이터·실기 모두 반드시 설치할 한글 업데이트** |

본편 CCI와 CIA에는 같은 게임 콘텐츠가 들어갑니다. 사용할 환경에 맞게 하나를 고르면 됩니다. 기존 파일이 열려 있어 다른 이름으로 저장되는 경우에는 앱이 알려준 실제 저장 경로를 확인하세요.

## 3. 설치하고 실행하기

### Azahar

1. `File → Install CIA…` 메뉴에서 **한글 업데이트** 파일 `YW3_Sukiyaki_KO_update4.cia`를 설치합니다.
2. 설치 완료 메시지를 확인합니다.
3. `File → Load File…` 메뉴에서 `YW3_Sukiyaki_KO_base.cci`를 열어 실행합니다.

본편 CIA를 쓰려면 그것도 `Install CIA…` 메뉴로 설치한 뒤 게임 목록에서 실행하세요. CIA를 목록에 추가하거나 폴더에 복사하는 것만으로는 설치되지 않습니다. 설치가 진행 중일 때 게임을 실행하지 마세요.

### 3DS 실기

Luma3DS와 FBI를 사용하는 환경을 기준으로 합니다. 기존 세이브가 있다면 먼저 Checkpoint 등으로 백업하세요.

1. `YW3_Sukiyaki_KO_base.cia`와 `YW3_Sukiyaki_KO_update4.cia`를 SD카드에 복사합니다.
2. 3DS를 켜고 FBI에서 **두 CIA를 모두 설치**합니다.
3. 설치 완료 후 HOME 메뉴에서 게임을 실행합니다.

앱이 만든 CIA에 GM9 암호화를 추가로 해야 하는 것은 아닙니다. 설치 오류가 나면 오류 코드로 원인을 확인하세요. 본편·티켓·DB를 일괄 삭제하는 절차는 안내하지 않습니다.

**실기 검증 상태:** CIA 생성 오류는 v1.7.8에서 수정했지만, 해당 버전의 실기 설치·부팅 성공은 아직 재확인이 필요합니다.

## 자주 묻는 질문

### 한글이 네모로 깨지거나 일본어가 많이 남아요

**가장 먼저 한글 `update4.cia`를 설치했는지 확인하세요.** 패치할 때 업데이트 원본을 선택했더라도, 완성된 업데이트를 사용하는 에뮬레이터나 실기에 따로 설치해야 합니다.

실제 제보에서는 본편만 설치된 Azahar에 한글 업데이트를 설치하자 오프닝 자막이 정상 한글로 표시됐습니다. 폰트·렌더러 변경 없이 해결됐으며, 사용자도 정상 표시를 확인했습니다. [해결 기록 #28](https://github.com/spidychoipro/YW3-KO-Patcher/issues/28)

둘 다 설치했는데도 문제가 남으면 앱 버전, 실행 환경, 설치한 파일명, 깨지는 화면과 진행 기록을 이슈에 올려 주세요. 글자가 깨진다는 이유만으로 시스템 폰트 문제라고 단정하지 않습니다.

### 예전에 만든 본편 CCI가 있어요

에뮬레이터에서는 한글 업데이트 CIA를 설치하고 기존 CCI를 그대로 실행할 수 있습니다.

실기용 본편 CIA가 필요하면 최신 앱의 **기존 CCI → CIA**에서 변환하세요. **이 기능은 본편 형식만 바꾸며, 한글 업데이트를 합치거나 설치하지 않습니다.** 업데이트 CIA도 별도로 필요합니다.

### 원본이나 결과 검증에서 실패해요

본편이 일본판 스키야키 v0인지, 업데이트가 Update 4.0인지 먼저 확인하세요. 앱의 **진행 기록 보기**에서 정확한 오류를 확인할 수 있습니다. 검증 실패한 결과를 정상 파일로 취급하지 마세요.

### 앱 업데이트와 한글 패치 업데이트는 다른가요?

네. 앱은 **업데이트 확인** 버튼으로 새 실행 파일을 확인합니다. 한글 패치는 **한글 패치 시작** 시 제작팀의 최신 지원 배포본을 확인합니다. 새 한글 패치를 적용할 때는 원본 파일로 다시 작업하세요.

## 제작팀과 프로젝트 안내

한국어 번역과 패치 데이터의 제작자는 [공식 한글 패치 제작팀](https://github.com/TeamLimRyan/YW3_SUKIYAKI_KOREAN_LOCALIZATION_RELEASE)입니다. 이 저장소는 패치 다운로드·적용·형식 변환을 돕는 앱을 제공합니다. 게임 원본과 패치 데이터는 앱에 포함하지 않습니다.

일부 이미지·전자 설명서 등에 일본어가 남는 범위는 제작팀 배포 문서를 확인하세요. 앱의 파일 검증 통과가 게임 전체 구간의 번역·실행 검증을 뜻하지는 않습니다.

입력 형식, 키 파일, 자동 다운로드·검증 방식과 소스 실행 방법은 [고급 사용 및 개발 안내](docs/advanced.md)에 정리했습니다.
