# 요괴워치3 스키야키 한국어 패치 적용기

본편 롬 파일과 업데이트 파일, 딱 두 개를 고르면 제작팀 공식 한글 패치(v1.0)를 자동으로 적용하는 Windows 프로그램입니다.

- 원본은 건드리지 않고 결과 파일을 새로 만듭니다.
- 파일 이름이나 지문 검사로 선택을 막지 않습니다. 두 파일을 그냥 고르면 됩니다.
- 패치 파일과 xdelta3는 처음 실행할 때 공식 배포처에서 자동으로 내려받아 캐시합니다.
- CIA로 넣어도 됩니다. 암호화되어 있으면 풀고, CCI가 아니면 CCI로 바꾼 뒤 패치합니다.

배포처: <https://github.com/TeamLimRyan/YW3_SUKIYAKI_KOREAN_LOCALIZATION_RELEASE>

## 사용법

1. `YW3-KO-Patcher.exe`를 실행합니다.
2. **① 본편 롬**에 일본판 본편 파일을 고릅니다. 복호화 CCI가 가장 빠르고, CIA나 NCCH도 됩니다(자동 변환).
3. **② 업데이트 파일**에 Update 4.0 CIA를 고릅니다. 암호화되어 있어도 됩니다.
4. **③ 저장 위치**는 본편 롬 옆 `YW3_KO` 폴더로 자동 지정됩니다. 바꾸고 싶으면 **변경**을 누릅니다. 결과 두 개가 합쳐 약 3.5GB이고 변환 임시 파일까지 쓰기 때문에 8GB 이상 남은 드라이브를 권장합니다.
5. 두 파일을 고르면 아래에 "준비 완료"가 뜨고 **한글 패치 시작** 버튼이 켜집니다. 누르고 기다리면 끝납니다. 처음 한 번은 패치 파일(약 79MB)을 내려받느라 조금 더 걸립니다.
6. 끝나면 진행률이 100%가 되고 저장 폴더가 자동으로 열립니다. 그 폴더에 두 파일이 생깁니다.
   - `YW3_Sukiyaki_KO_base.cci` (본편, 약 3.05GB)
   - `YW3_Sukiyaki_KO_update4.cia` (업데이트, 약 187MB)

에뮬레이터(Azahar)에서는 업데이트 CIA를 먼저 설치하고, 그다음 본편 CCI를 실행합니다. 한쪽만 패치하면 번역이 빠집니다.

## 자동 변환 (CIA / NCCH)

고른 파일이 패치 대상과 형식이 다르면 알아서 맞춰 놓고 진행합니다. 변환은 저장 폴더 안 `_YW3_KO_work`에서 하고, 끝나면 지웁니다.

| 넣은 파일 | 하는 일 | 패치 |
|---|---|---|
| 복호화 CCI | 없음 | 바로 |
| 암호화 CCI | **지원 안 함** (콘솔 키 필요) | 안내하고 멈춤 |
| 복호화 CIA | CCI로 다시 묶기 | 변환본으로 |
| 암호화 CIA | 타이틀 키로 내용 복호화 → CCI로 다시 묶기 | 변환본으로 |
| NCCH (`.app`/`.cxi`) | CCI로 감싸기 | 변환본으로 |
| 업데이트 CIA (암호화) | 내용만 복호화 | 복호화본으로 |
| 업데이트 CIA (복호화) | 없음 | 바로 |

변환본으로 패치하면 결과 헤더가 배포팀이 만든 기준 CCI와 달라서 결과 SHA-256이 공식 값과 일치하지 않습니다. 이 경우 파일을 지우지 않고 저장한 뒤 창에 "지문이 공식 값과 달라요"라고 알려줍니다. 그냥 넣은 원본이 지원 버전이 아니어서 지문이 다른 경우에는 실패로 처리하고 결과를 남기지 않습니다.

## 암호를 풀려면 keys.txt

암호화된 CIA는 그 타이틀의 타이틀 키가 있어야 내용을 풀 수 있고, 타이틀 키는 3DS 공통 키로 한 번 더 감싸여 있습니다. 이 앱은 공통 키만 있으면 됩니다.

`keys.txt` 파일을 만들고 아래처럼 한 줄을 넣어 롬 파일과 같은 폴더에 두세요.

```
common: 0123456789abcdef0123456789abcdef
```

- 32자리 16진수 한 줄만 있어도 됩니다.
- 찾는 순서: `YW3KO_KEYS` 환경 변수가 가리키는 파일 → 본편 폴더 → 업데이트 폴더 → 캐시 폴더(`%LOCALAPPDATA%\YW3KoPatcher`)의 `keys.txt` / `aes_keys.txt`.
- 키는 앱에 넣지도, 내려받지도 않습니다. 본인 콘솔에서 추출한 키를 직접 두세요.
- 키가 없으면 시작 전에 준비 줄에 안내가 뜨고, 시작하면 어느 파일 때문에 막혔는지 알려줍니다.

## 대상 원본

| 역할 | 파일 | 바이트 | SHA-256 |
|---|---|---:|---|
| 본편 | 복호화 CCI, 일본판 v0 | 3270860800 | `d98a9430f3edc0b25fc1a4e0d147d0b976db1b0bdce8e042c50f0e84a738f4d8` |
| 업데이트 | 복호화 CIA, Update 4.0 | 196408320 | `95d5e28eb4920a68bfc3c0ae407a308ddc06a11ab229da3d28cfa4976af58082` |

프로그램이 미리 지문을 검사해서 막지는 않지만, 위 두 원본이 아니면 xdelta3가 중간에 거부합니다. 그때는 "원본이 패치 대상 버전과 다릅니다"라는 안내가 뜨고 결과 파일은 남지 않습니다.

위 표는 기준이 되는 원본입니다. 같은 게임의 다른 형식(CIA, NCCH, 암호화 CIA)을 넣으면 아래 자동 변환을 거쳐 위 원본과 같은 내용으로 맞춘 뒤 패치합니다.

## 파일 자동 판별

파일을 고르면 헤더만 읽어서 컨테이너 종류(CCI/CIA/NCCH), 암호화 여부, 타이틀 ID를 확인하고 입력칸 아래에 짧게 보여줍니다. 이 판별에는 키를 쓰지 않습니다. 암호화된 CIA는 NCCH 헤더가 안 보이므로 티켓/TMD에서 타이틀 ID를 읽습니다.

- 복호화 CCI + 요괴워치3 본편 타이틀 → "✓ 본편: 정상 (복호화 CCI)"
- 복호화 CIA + 요괴워치3 업데이트 타이틀 → "✓ 업데이트: 정상 (복호화 CIA)"
- 암호화된 본편 CIA → "암호화된 CIA예요. 암호를 풀어서 CCI로 바꾼 뒤 패치할게요"
- 암호화된 업데이트 CIA → "암호화된 CIA예요. 암호를 푼 뒤 패치할게요"
- 암호화된 본편 CCI → "카드 이미지 암호는 콘솔 키가 필요해서 이 앱에서는 못 풀어요"
- 본편/업데이트를 바꿔 넣음 → "두 칸을 서로 바꿔 보세요"
- 다른 게임/다른 타이틀 → 타이틀 ID와 함께 경고

경고가 떠도 시작 버튼은 그대로 눌립니다. 선택을 막지 않고, 확인 대화상자도 띄우지 않습니다.

## 참고

- 결과 파일은 항상 SHA-256으로 확인한 뒤에만 최종 이름으로 바뀝니다. 검증에 실패하면 결과물을 남기지 않습니다. 단, 변환본으로 패치한 경우는 위 설명대로 지문이 달라도 저장하고 알려줍니다.
- 끝나면 저장 폴더가 자동으로 열리고, 창에도 **저장 폴더 열기** 버튼이 생깁니다.
- **진행 기록 보기**를 누르면 자세한 로그와 **패치 데이터 새로 받기** 버튼이 나옵니다.
- 패치 파일은 재배포가 금지되어 있어 exe에 넣지 않았습니다. 항상 공식 릴리즈에서만 받습니다.
- 내려받은 파일은 `%LOCALAPPDATA%\YW3KoPatcher`에 캐시되고, 프로그램의 **패치 데이터 새로 받기** 버튼으로 지울 수 있습니다.
- 게임 원본·키·펌웨어·세이브는 프로그램이 읽거나 보내지 않습니다. 네트워크는 패치 파일 내려받기에만 씁니다.

## 안 될 때

- **"원본이 패치 대상 버전과 다릅니다"**: 고른 파일이 위 표의 원본이 아닙니다. 복호화된 파일인지, 본편과 업데이트를 바꿔 넣지 않았는지 확인하세요.
- **"결과 지문이 다릅니다"**: 결과물을 설치하지 말고 원본을 다시 확인하세요. 프로그램이 해당 결과 파일을 지웁니다.
- **"변환본으로 패치해서 지문이 공식 값과 달라요"**: 변환한 파일로 패치해서 생기는 정상적인 차이입니다. 파일은 저장됐으니 그대로 쓰면 됩니다. 다만 에뮬레이터에서 안 돌아가면 원본 복호화 CCI로 다시 해보세요.
- **"keys.txt가 필요합니다"**: 암호화된 CIA를 넣었는데 공통 키가 없습니다. 위 형식대로 `keys.txt`를 만들어 롬 옆에 두세요.
- **"암호화된 CCI"**: 카드 이미지 암호는 그 게임을 덤프한 3DS의 콘솔 키가 필요합니다. 이 앱은 콘솔 키를 다루지 않습니다. 복호화된 CCI를 준비하세요.
- **실행이 안 되고 SmartScreen 경고**: 서명 없는 exe라서 나오는 경고입니다. 정보 → 추가 정보 → 실행.
- **내려받기 실패**: 사내망·백신이 GitHub를 막는 경우가 있습니다. `%LOCALAPPDATA%\YW3KoPatcher`를 지우고 다시 시도하거나, 릴리즈 zip을 직접 받아 `%LOCALAPPDATA%\YW3KoPatcher\YW3S_Korean_Patch_v1.0.zip`에 넣으면 그 파일을 씁니다.
- **진행률이 멈춘 것 같음**: 본편 패치가 3GB 파일을 다시 쓰기 때문에 몇 분 걸립니다. CIA 변환까지 하면 복호화·복사가 한 번 더 붙습니다. 디스크가 느리면 더 걸립니다.

## 개발

```powershell
# 실행 (파이썬 3.10+)
python .\yw3ko_patcher.py

# 핵심 기능 점검 (xdelta3 내려받기, 패치 추출, 적용/실패 처리, GUI 생성)
python .\tools\smoke_test.py

# 배포 exe 자체 점검 (다운로드·압축 해제·지문 확인)
.\dist\YW3-KO-Patcher.exe --selftest "$env:TEMP\yw3_selftest.log"

# 단일 exe 빌드 -> dist\YW3-KO-Patcher.exe
pwsh -File .\build.ps1
```

- `yw3ko_patcher.py` : GUI와 패치 로직 (표준 라이브러리만 사용)
- `yw3convert.py` : CIA/NCCH → CCI 변환, CIA 복호화, 키 파일 읽기 (AES-CBC는 Windows CNG `bcrypt.dll` 사용, 외부 패키지 없음)
- `tools/make_icon.py` : `build/app.ico` 생성
- `tools/smoke_test.py` : 스모크 테스트 (가짜 CIA/NCCH로 변환·왕복 검증 포함)
- `build.ps1` : PyInstaller 단일 exe 빌드

xdelta3는 GPL 라이선스 도구라서 저장소에 넣지 않고, 공식 3.2.2 배포본을 지문 확인 후 내려받습니다.
